# dsh-feiyu-owner（肥鱼 · 专属主人）

给 DSH 里的肥鱼一份**只属于主人**的档案：认得主人、记得主人、多人场合优先主人，其他人照常回应。

> 状态：九个代码文件语法通过、26 项测试通过（含宿主半端假 ctx 与浏览器半端渲染冒烟）。
> 真实 DSH 里**插件本体已经跑起来**（日志有 `apply 启动`）；0.2.0 新加的**界面弹窗**要重启一次 DSH
> 才会被扫描到，**还没在真实浏览器里亲眼看过** —— 下面写清了怎么看。

## 谁是主人（唯一）

- 主人 = **安装者**在自己的 Agent 对话框里给出的那**一个** QQ 号，跟是不是群主、管理员**无关**。
- 装好后 agent 会主动问「你的 QQ 号是多少？」，只问一次、只在非群会话问；答案用 `feiyu_owner_setup` 工具保存。
- 只锁一个号：给多个会被拒绝；换人必须显式 `force=true`，且只能在本地对话里换。
- 群号**不是必填**，空着就自动关掉群增强，之后可补。

## 装好之后会发生什么（0.2.0）

装完**重启一次 DSH**，打开界面就会自己弹一张卡片（`shell.overlay` 里的全局对话框）：

> 咦，我是不是被装了一个「主人插件」？

卡片里填 QQ 号 → 点「就是我，绑定」，当场就绑上；不用去对话里说，也不用先打开设置页。
两条路读的是同一份状态，所以不会两边都问、也不会都不问：

| 情况 | 界面弹窗 | 对话里追问 |
|---|---|---|
| 刚装好、没绑 | 弹 | 不问（弹窗已经替你问了） |
| 弹窗露过脸但没处理 | 下次打开还弹 | 不问 |
| 点了「先不用」 | 不再弹 | 不问（以后只走设置页手动绑） |
| 已经绑好 | 不弹 | 不问 |
| 界面那半没加载（命令行版 / bundle 没起来） | 不弹 | **问一次**，只在非群会话 |

实现上分两半：`lib/index.js` 出状态和落盘（`/onboard`、`/bind` 两条路由），`lib/client.js` 只负责渲染卡片。
绑定接口只认**本机回环地址**的请求；已绑定时想换别人的号会被拒（换人要回对话里明确说）。


## 能做什么

- 认主人：只认绑定的那个 QQ；认不出来就谁都不当主人（绝不按昵称、群名片猜）。
- 记主人：每天 04:30 把主人前一天的话提炼成档案，带出处；只有这一步调模型，后台跑。
- 用档案：每轮注入最相关的几条（同步、不联网）；群会话只给 `scope=public`，私聊内容不进群。
- 主动开口：按冷却和安静时段说一句，这句话由模型按档案现写（群里只喂 public 素材），失败才用兜底句。
- 可查看可纠正：设置页看/钉住/删；删掉的按事实键进黑名单，不再复活。

## 还不能做

- **群里稳定认出主人**：QQ 桥只给 `kind:'qq'`，没有发送者 id；正文前的「昵称（QQ号）：」可被伪造。现在的做法是用 OneBot 反查，**未实测**，查不到/多义就不认。
- **保证 @ 成功**：桥只发纯文字，真 @ 要走 OneBot `send_group_msg`，未实测。
- 语音、心情、B 站联动：不在本插件范围。

## 数据位置（只写 E 盘）

默认 `E:/AI_Workspace/Data/feiyu-owner/`，可用 `FEIYU_OWNER_DATA_DIR` 覆盖，但**不在 E 盘就整体拒写**，只打一行错误。

```
config.json   profile.json   digests/YYYY-MM-DD.json   log.jsonl   backup/（留最近 20 份）
```

## 配置要点

| 键 | 默认 | 说明 |
|---|---|---|
| `enabled` | `false` | 总开关；关着也能绑定，只是不注入不发消息 |
| `dryRun` | `true` | 试运行，只写日志 |
| `ownerQq` | `[]`（空） | **只存一个** QQ |
| `ownerName` | `主人` | 称呼 |
| `digestAt` | `04:30` | 每日整理时间 |
| `group.groupId` | 空 | 群号，可空 |
| `group.enabled` | `false` | 群增强（反查 + 发带 @ 消息） |
| `group.logOnly` | `true` | 群消息只记日志不真发 |
| `installId` / `installedAt` | 自动生成 | 这一次安装的标识，界面弹窗认它 |
| `onboardSeenAt` | `null` | 弹窗在界面里露过脸的时间 |
| `onboardDismissedAt` | `null` | 点过「先不用」→ 以后不再自动弹 |
| `onboardBoundAt` / `onboardBoundFrom` | `null` / `''` | 从哪条路绑的（`dialog` 或对话） |

## 结构

`lib/core.mjs` 纯逻辑 · `store.mjs` 存储 · `host.mjs` 宿主交互 · `digest.mjs` 每日整理 ·
`speak.mjs` 主动句生成 · `onebot.mjs` QQ 增强 · `tool.mjs` 对话内绑定 · `page.mjs` 设置页 ·
`client.js` **界面弹窗（浏览器半端）** · `index.js` 入口 · `tests/`

## 自查（不用打开界面也能看）

```
node E:/AI_Workspace/Projects/dsh-feiyu-owner/tools/verify.mjs http://127.0.0.1:<端口>
```

里面会多打两行：`/onboard` 状态接口是否活着、以及**弹窗到底在界面里露过脸没有**
（`log.jsonl` 里对应 `弹窗已经在界面里出现` 那一行）。没有露脸通常就是 client bundle 还没被扫描到 → 重启 DSH。
